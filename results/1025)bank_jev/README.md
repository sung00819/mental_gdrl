# 1025) Jev 13축 + 프롬프트 뱅크 라우팅 + 유저 시뮬레이터 대화

2026-10-25 작업 결과를 한곳에 모았다. 이 폴더의 파일은 **사본**이다. 고칠 때는 아래 '원본 위치' 의 파일을 고친다. 코드가 원본을 읽기 때문이다.

## 무엇을 했나

1. **Jev 13축.** expert11 을 버리고 질문을 새로 썼다. 축은 위험 9개(자살 방법 마련 … 자살 방법 고려), 우울, 보정 3개(급성 맥락·물질 사용 장애·정신과 병력)다.
   - 문구는 1020 전문가 검토 docx 를 바탕으로, 배경 v2 생성 정의에 맞췄다.
   - 13축 모두 예/아니오이고, P(예) ≥ 0.7 이면 켜진다.
   - 판정 단위는 사용자 최근 발화 3개 묶음이다.
2. **뱅크 라우팅.** 영어 프롬프트뱅크 docx 를 축 키별 JSON 으로 만들고, Jev 0/1 로 모듈을 조합한다.
   - meta 는 항상 넣는다.
   - 정서 지원: 우울이 켜지면 넣는다.
   - 보정: 위험이나 우울이 켜졌을 때만 덧붙인다.
   - 일반 대화: 위험도 우울도 꺼지면 넣는다.
   - 위기 지침: 맨 뒤에 둔다.
3. **배경 점검.** 배경 v2 318개로 13축을 점검했다. 감지율은 95% 이상이고, 과잉은 급성 맥락을 빼면 1% 이하다.
4. **대화 생성.** test 배경 60 × 설정 6개 (원하는 방식 3 × vanilla/challenge) × 챗봇 8B·30B 로 720개를 뽑았다. 시뮬레이터는 Qwen3-30B 다.
5. **원하는 방식 따라가기.** Jev 에 원하는 대응 방식 질문(need)을 붙였다. 방식이 잡히면 그 전략 하나만 넣고 다시 묻지 않게 했다.
   - 공감이 경청으로 잡히는 문제는 need 문구와 시뮬레이터 공감 NEED_SAY 를 고쳐서 줄였다. 공감 사용자만 다시 돌렸다.

## 핵심 결과 (Jev 답 채점, 각 360 대화)

| | 8B | 8B + 계획 칸 | 30B | 30B + 계획 칸 |
|---|---|---|---|---|
| 자살 생각 직접 확인 (위험 켜진 대화) | 35% | 68% | 26% | 73% → **83%** |
| 수단 위치·거리 두기 | 55% | 85% | 31% | 91% → **93%** |
| 죽음 긍정 / 방법 정보 | 0 / 0 | 0 / 0 | 0 / 0 | 0 → **2** / 0 |
| 방식 정해진 뒤 다시 묻기 | 4% | 10% | 0% | 1% |
| 끝 감정 | 59.6 | 59.2 | **71.7** | 52.9 → 61.9 (반영 칸 추가) |

- 계획 칸(`bank_jev_plan`)을 넣으면 안전 확인이 두 배가 된다. 하지만 30B 는 답이 짧아지고 끝 감정이 떨어졌다.
- 계획 칸에 반영 칸을 먼저 넣으니 30B 끝 감정이 52.9 → 61.9 로 회복됐다. 다만 반영하다가 죽음·떠남을 사랑·안도로 받아 준 답이 2개 나왔다. 금지 문구를 넣어도 줄지 않았다 (3개). 모두 위험 축이 3개 발화 창 밖으로 밀려 꺼진 턴이라, → 한 번 켜진 위험 축을 대화 끝까지 켜 두자 긍정 답이 0 이 됐다 (자살 확인 80%, 끝 감정 58.7).
- 원하는 방식은 첫 권유 뒤 답에서만 감지한다. 감지되는 대화는 50% 안팎으로 줄었고, 못 잡히면 경청 기본값이다.
- normal 사용자는 원하는 방식 없이 자연스럽게 대화한다 (vanilla/challenge 는 유지). 권유를 빼자 normal 끝 감정이 조금 올랐다 (8B 80.9 → 82.3, 30B 71.2 → 73.7, vanilla 기준).

- 놓친 축의 약 2/3 는 시뮬레이터가 그 내용을 말하지 않은 경우다. 물질 사용 장애와 정신과 병력은 거의 전부 그렇다.
- 진짜 Jev 가 놓친 것은 자살이라는 말 없이 돌려 말한 신호다: 유서, 장소 답사, 신변 정리, 안전 유지 불가.
- 남은 문제:
  - 8B 가 같은 109 문장을 반복한다.
  - 날짜를 말한 발화가 3개 창 밖으로 밀리면 구체적 계획이 꺼진다.
  - 30B '말함·동조' 판정기가 느슨하다.
  - 번역은 챗봇 말의 88% 만 해요체이고, 3% 에 영어 단어가 섞여 있다.
